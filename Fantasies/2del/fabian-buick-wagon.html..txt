        <div class="forensic-text">
            <p>Fabian down at the shop has this old Buick Estate Wagon sitting around—the kind of beat-up land yacht most people walk right past without giving a second thought. But visual mental exercises exist to squeeze style out of unlikely places.</p>
            <p>This layout explores what happens when you take that long-roof platform and give it the full custom treatment: dropping an LS3 V8 backed by a heavy-duty 4L80-E transmission, slinging the chassis over an air bag suspension, keeping the original BOP rear end, and executing seamless body mods like shaved door handles and re-engineered rear suicide doors.</p>
            <p>We rendered two distinct styling philosophies: a sleek deep-blue street custom with custom modern wheels, and an urban lowrider iteration featuring multi-pattern graphic paint, wire wheels pushing into Donk proportions, and ground-effect lighting. It's a build that will likely never touch metal, but the render turned out too clean to leave on the hard drive.</p>

    <script>
        const viewer = document.getElementById('imageViewer');
        const viewerImg = document.getElementById('viewerImg');
        const viewerCaption = document.getElementById('viewerCaption');

        function openViewer(src, altText) {
            viewerImg.src = src;
            viewerCaption.innerText = altText || '';
            viewer.classList.add('active');
            document.body.style.overflow = 'hidden';
        }

        function closeViewer() {
            viewer.classList.remove('active');
            document.body.style.overflow = '';
        }

        document.addEventListener('keydown', (e) => {
            if (e.key === 'Escape' && viewer.classList.contains('active')) {
                closeViewer();
            }
        });
    </script>
